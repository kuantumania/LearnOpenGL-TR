Joey de Vries tarafından hazırlanan ve dünya çapında bilgisayar grafikleri ve oyun geliştirme alanının 1 numaralı başucu kaynağı kabul edilen **[LearnOpenGL.com](https://learnopengl.com)** rehberinin modern, açık kaynaklı ve topluluk odaklı Türkçe çeviri projesi.

## 🎯 Hedefimiz

Modern grafik programlama (OpenGL 3.3+ Core Profile, GLSL, Aydınlatma Modelleri, PBR ve Motor Mimarisi) alanında Türkiye'deki oyun geliştiricilerine, teknik sanatçılara ve bilgisayar mühendislerine eksiksiz, akıcı ve terminolojiye sadık bir Türkçe kaynak sunmaktır.

---

## 🛠️ Yerel Geliştirme Ortamı

Bu dokümantasyon **Material for MkDocs** altyapısıyla çalışmaktadır. Yerelde önizlemek için:

```bash
# Gerekli bağımlılıkları yükleyin:
pip install mkdocs-material

# Canlı geliştirme sunucusunu başlatın:
mkdocs serve
```

Tarayıcınızdan `http://localhost:8000` adresine giderek anlık olarak değişiklikleri görebilirsiniz.
